# S2T

A macOS menu bar dictation app for Apple silicon and Intel, macOS 14 or later.

[Download S2T](https://github.com/conrad312/S2T/releases) and select the newest DMG.

Drag S2T into Applications, open it, then choose Set up dictation from the menu bar. The setup menu guides you through permissions, your provider keys, and a shortcut test. Hold Fn to speak and release to finish, or tap to start and tap again to finish.

This beta is locally signed and not notarized. macOS may require [Open Anyway](https://support.apple.com/en-us/102445). You need your own funded provider account. For dictation without text cleanup, select Use Verbatim during setup.

This repository hosts public downloads and setup instructions. The ZIP in each release includes the full getting-started guide.
